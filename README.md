## Teste Prático Aprendiz Front-End O Povo
Este repositório contém a resolução do teste técnico para a vaga de Desenvolvedor Front-end. O projeto consiste na criação de uma página de detalhes de filmes ("Barbie"), focando em fidelidade visual, semântica HTML e responsividade.

## 🚀 Tecnologias Utilizadas

* *HTML5:* Estruturação semântica de dados.
* *CSS3:* Estilização avançada com Flexbox e Grid Layout.
* *Metodologia Responsiva:* Mobile-first e adaptação para Tablet e Desktop.
* *Google Fonts:* Utilização da tipografia Montserrat para alinhar ao design.

## 📋 Funcionalidades e Diferenciais

* Fidelidade ao Design: Layout desenvolvido seguindo rigorosamente as especificações do Adobe XD fornecidas.
* Estrutura de Conteúdo:
    * Seção principal com Poster e informações técnicas (Gênero, Sinopse, Elenco, Orçamento, etc).
    * Seção de Elenco organizada em formato de carrossel horizontal/grid responsivo.
    * Seção de Resenhas com cards estilizados.
* Componentes Customizados: Botões "Ver mais" e avatares de atores com máscaras circulares.
* *100% Responsivo: A interface se adapta perfeitamente a dispositivos móveis, garantindo boa usabilidade em qualquer tamanho de tela.
